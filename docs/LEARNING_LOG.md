An unrelated process held port 8000, so the API ran temporarily on 8010. |
| 2026-11-19 | Prompt 7: free data source audit | Audited no-key public APIs from Iran with VPN and bounded requests | CoinGecko and Binance supplied measured 365-day BTC/ETH/SOL/BNB market history; DefiLlama supplied measured chain TVL and stablecoin histories; Coin Metrics community timeseries returned HTTP 400 for the tested metrics, while its catalog reached 200. CoinGecko stopped BNB chart probing after HTTP 429 with Retry-After 60. The free market/RPC sources can be used where measured, but unsupported on-chain active-address, transaction, fee, TVL, stablecoin, and validator components must remain unavailable rather than estimated. |
| 2026-11-19 | Prompt 7B: audit evidence correction | Reworked failed-source labels and measured source depth separately from probe windows | An HTTP 400 or 403 is evidence about that request, not proof that a metric is absent; `NOT AVAILABLE FREE` requires catalog/documentation evidence, while unsupported community-tier requests remain `UNVERIFIED` and PoS hashrate remains `NOT APPLICABLE`. |
| 2026-11-19 | Prompt 8B: additional ingestion providers | Added Coin Metrics, DefiLlama, and BTC network series with source-specific coverage and quality checks | Coin Metrics returns values with more decimal places than PostgreSQL `NUMERIC(38,12)` stores, so normalize with `Decimal` rounding rather than discarding valid rows. Blockchain.info caps chart response spans and labels transaction fees in BTC; fetch bounded sequential windows, convert fees with same-day Binance closes, and record missing dates rather than filling gaps. |
| 2026-11-19 | Prompt 8B2: discontinued series correction | Purged 1,961 legacy BNB Coin Metrics observations and hardened freshness and quality checks | HTTP 200 with empty or stale data is not availability; catalog end dates, not transport success, determine whether a series is current. |
| 2026-11-19 | BNB Chain and DefiLlama analytics | Audited `bnb_bsc` catalog evidence and ingested eligible DefiLlama DEX-volume and protocol-fee series | A populated daily chart can be useful while still lacking explicit unit metadata; retain the raw `Decimal` values and gaps, label the unit unverified, and keep protocol fees separate from network fees. |
| 2026-11-20 | Scheduled ingestion worker | Added an isolated APScheduler process with daily update and CoinGecko snapshot jobs, PostgreSQL advisory locks, and bounded failure handling | Separate-process schedulers can overlap across multiple instances; a non-blocking database advisory lock prevents duplicate writes, while run records preserve rate-limit and failure outcomes. CoinGecko snapshots are forward-collected only and never presented as historical backfill. |
| 2026-11-20 | DefiLlama composition and score policy | Recorded protocol contributors and narrowed score candidates | Chain-filtered protocol totals can combine exchange, staking, builder, lending, and issuer activity; they are ecosystem proxies, not direct chain usage. Treat all protocol fees and BTC DEX totals as context only, use other chain DEX totals only as low-weight candidates, keep units unverified, and prefer robust score statistics. |
| 2026-11-20 | RPC liveness and admin monitoring | Added sanitized per-chain probes, worker scheduling, retention, role-protected read-only monitoring, and role bootstrap CLI | Public RPC URLs can contain credentials when overridden, so persist provider labels and short error codes only. A single block-time lookup failure on Solana should retain its slot with a null age. |
